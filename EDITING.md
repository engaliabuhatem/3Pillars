# Editing the 3 Pillars website

Everything you see on the website is changed in the admin at
**https://admin.<your-domain>/admin/**. Changes appear on the live site within a few
seconds. You never need a developer or a "redeploy".

## Three rules

1. **Nothing goes live until it is approved.** Every item has a *Status*: "Awaiting
   approval" or "Live". Only people in the **Approver** role can change it. Use the
   **Publishing** tab on an item, or tick items in a list and choose
   *Approve for publication* from the actions menu.
2. **Fill in both languages.** Each form has a **Content EN** and a **Content AR** tab.
   If an Arabic field is empty the site shows the English text, and on the staging site
   it is marked "Arabic translation pending".
3. **Every image needs a description** in English and Arabic (for people using screen
   readers). The form will not save without them.

## Where to change what

| To change… | Go to… |
|---|---|
| The big headline, sentence and buttons at the top of the home page | Site settings → **Hero** tab |
| The background video or its still image | Site settings → **Hero video** tab (desktop MP4 up to 8 MB, 10–20 s loop, with a poster image, which is required; optionally a portrait mobile MP4 up to 4 MB and a mobile poster at least 720 × 1280, which phones use instead of the desktop ones) |
| The order of the home page sections, or hide one | **Home sections** — drag rows to reorder; untick *Visible* to hide |
| A section's small heading, title, intro or button | **Home sections** → click the section |
| The three pillars | **The three pillars** |
| The figures band (e.g. "25+ projects") | **Key figures** — each needs a source note |
| Client / partner logos | **Clients & partners** — tick *Show in the logo strip* (only with the client's permission) |
| Quotes from clients | **Testimonials** — real, attributed quotes only |
| Services, their deliverables, steps and questions | **Services** (tabs at the top: Deliverables, Delivery steps, Questions & answers) |
| The service shown large on the home page | **Services** → tick *Featured* |
| Sectors | **Sectors** |
| Projects / case studies, their results and photos | **Projects** (tabs: Results, Gallery). The project value stays private unless *Show the value publicly* is ticked |
| Projects on the home page | **Projects** → tick *Featured* |
| The approach timeline (Initiation → Closeout) | **Approach stages** |
| Articles and news | **Insights** |
| About, Approach, Careers, Privacy, Terms, Cookies and the intro text of every list page | **Pages** — each page is built from blocks: text, image + text, figures, quote, gallery, questions, call to action. Drag blocks to reorder |
| Team / leadership | **Team** → tick *Leadership* to show on About |
| Offices, map and contact details per office | **Offices** |
| Certifications and memberships | **Certifications** |
| The capability statement PDF | **Downloads** → tick *Capability statement*. Tick *Ask for contact details first* to collect leads |
| Job openings | **Jobs** — untick *Accepting applications* to close one |
| The menu at the top and the links in the footer | **Navigation** (header items) and **Footer columns** |
| A page's address (slug) | The *Slug* field. The old address keeps working automatically (see **Redirects**) |
| Search engine title and description, share image | The **SEO** tab on any page, service, project or article |
| Phone, email, address, social links, WhatsApp button | Site settings → **Contact** |
| Who receives new enquiries by email | Site settings → **Forms** → one email per line |
| The cookie message | Site settings → **SEO & analytics** |
| Hide the whole site behind "coming soon" | Site settings → **Switches** |

## Leads and the pipeline (BD team)

New submissions arrive in **Proposal requests**, **Enquiries**, **Download leads** and
**Applications**, and by email to the addresses in Site settings → Forms.

- Each request has a **Stage** (New → Qualified → Proposal sent → Won / Lost), an
  **Owner** and a **Next follow-up** date. Overdue follow-ups appear on the dashboard.
- **Internal notes** at the bottom of a request are never sent to anyone.
- What the person submitted cannot be edited — it is the record of what they sent.
- Attachments and CVs are private: download them with the *Download* link in the admin.

## Roles

| Role | Can |
|---|---|
| Editor | Write and change all website content (not approve it) |
| Approver | Approve content for publication, or take it back off the site |
| BD | Work the leads and pipeline |
| Admin | Everything, including staff users and roles |

Assign roles under **Configuration → Staff users** (a person can hold more than one).

## Before launch

Site settings → **Switches**: turn **Show content awaiting approval OFF** and
**Show the coming-soon page OFF**.
