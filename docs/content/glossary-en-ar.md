# English–Arabic glossary

The fixed terms used in every Arabic field `seed_content` writes. The Arabic is a draft in formal Modern Standard Arabic for a corporate B2B audience: every translated row is seeded with `ar_reviewed = False` until a fluent reviewer signs it off.

Use one term per concept, everywhere. If a reviewer changes a term, change it here first and then in every row.
